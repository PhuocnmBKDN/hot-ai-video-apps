# Application audit — 2026-10-28

Deployed to https://hotai.bro.io.vn/ on the owner's existing Cloudflare infrastructure.
Worker version: `0548362f-e6ef-4949-9f0f-75c4a56235ee`.
Additive D1 migration: `0015_query_indexes.sql` (indexes only).

## Changes

- Catalog and admin library: bulk-load episode, price, poster, sales and entitlement information instead of repeated per-film queries. Regression test bounds query count with 120 films. Add indexes for wallet, deposit and purchase history.
- Player: capture the correct video during cleanup, save position on close/page hide, serialize checkpoints, avoid duplicate writes, and prevent stale requests affecting a newly opened episode. Renew a paused/expired playback session with position retained; reconnect after browser back/forward cache. Navigation skips missing episode numbers.
- Playback authorization: heartbeats cannot revive a revoked lease or exceed two active players. Logout revokes that session's playback leases together with the login session.
- Wallet: separate lightweight balance polling from private paginated history. Add deposit/spending filters, page size and refresh controls. Poll less frequently while idle; explicit balance checks refresh history even when balance is unchanged. Add QR image failure guidance.
- Navigation: synchronize tabs/categories with URL and browser Back/Forward; avoid repeated deep-link opening and duplicate initial catalog loading.
- Admin and forms: handle loading and retry errors instead of flashing a login prompt; remove unused storage fetch; handle renamed genres case-insensitively without reinstating obsolete names. Add show/hide password and disable username auto-capitalization.
- Accessibility/mobile: trap modal keyboard focus and restore it after close; use 16px mobile fields to prevent iPhone input zoom; wrap long wallet/account content and action rows. Check responsive layout at 393×852 and the normal desktop viewport.
- API handling: reject malformed/non-object JSON, invalid pagination and unsupported mutation methods; distinguish duplicate usernames from database outages. Apply MIME-sniffing, anti-framing and basic CSP headers to static assets as well as API responses.
- Correct PWA description and privacy text to reflect per-film unlock rules and synchronized watch history; show a friendly page for unknown routes.

## Deferred / not changed

- No destructive production tests, real payments, permission changes, film deletion or media migration. These require deliberate owner action and could affect real customers. Transaction/delete/permission logic is covered with isolated database tests.
- No production stress test or independent penetration test; these could disrupt service or consume paid quotas. No verified CCU guarantee is claimed.
- No admin 2FA enrollment or stronger password/retry policy. The existing nonempty, maximum-30-character password rule and unrestricted retries follow the owner's explicit prior preference; changing them needs a separate decision.
- No external backup destination or automated restore drill configured; ownership, retention and any storage costs need a separate decision. Existing local originals and infrastructure were not removed.
- DRM/video encryption remains disabled as explicitly requested. Session authorization and browser download deterrents do not guarantee prevention of downloading or screen recording.
